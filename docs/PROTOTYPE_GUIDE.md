### 📱 3. قائمة الشاشات الـ 18 المصممة بالكامل

| رقم الشاشة | اسم الشاشة | الوصف ومحتوى الواجهة |
|:---:|:---|:---|
| **1** | **شاشة البداية (Splash Screen)** | هوية المنصة، الشعار اليمني الأصيل، اللون الأخضر التراثي (Deep Teal)، وزر البدء. |
| **2** | **شاشة تسجيل حساب جديد (Sign Up)** | اختيار نوع الحساب (باحث عن عقار / مالك ومكتب عقاري)، رقم الهاتف اليمني (+967)، البريد، وكلمة المرور. |
| **3** | **شاشة تسجيل الدخول (Login)** | إدخال رقم الهاتف/البريد، كلمة المرور، واستعادة الحساب أو الدخول السريع عبر OTP الواتساب. |
| **4** | **الشاشة الرئيسية (Home)** | شريط البحث السريع، فلاتر الصفقات (الكل / للإيجار / للبيع)، شرائح المحافظات، كروت العقارات الغنية، وشريط التنقل السفلي. |
| **5** | **شاشة نتائج البحث والعقارات (Search Results)** | تصفية متقدمة حسب نوع العقار (شقة، فيلا، أرض، عمارة)، الفرز حسب السعر، وعرض النتائج المطابقة. |
| **6** | **شاشة تفاصيل العقار (Property Details)** | معرض الصور، شارة التوثيق بالبصيرة الشرعية، السعر بالعملة، شبكة المواصفات (غرف، حمامات، مساحة باللبنة الصنعانية)، وزر توليد العقد. |
| **7** | **شاشة إضافة عقار جديد (Add Property)** | نموذج تفاعلي متكامل لإدخال تفاصيل العقار والنوع والأسعار، مع زر لتحديد الموقع على الخريطة. |
| **8** | **شاشة تحديد موقع العقار على الخريطة (Pick Location)** | خريطة تفاعلية مع علامة تحديد الموقع الدقيق (GPS Crosshair)، وعرض الإحداثيات وتأكيد الحي. |
| **9** | **شاشة المفضلة (Favorites)** | قائمة بالعقارات المحفوظة مع إمكانية الوصول السريع أو الإزالة بنقرة واحدة. |
| **10** | **شاشة الخريطة العقارية لليمن (Yemen Map Clusters)** | خريطة اليمن مع نقاط التجميع المكاني (صنعاء، عدن، تعز، حضرموت...) وكرت منبثق للعقار المختار. |
| **11** | **شاشة تفاصيل صاحب العقار والمكتب (Owner Profile)** | بيانات المالك/المكتب، رقم الترخيص العقاري، تقييمات العملاء، وأزرار التواصل الهاتفي والواتساب. |
| **12** | **شاشة إنشاء عقد إيجار (Rental Contract)** | نموذج عقد إيجار شرعي وقانوني وفق أحكام القانون المدني اليمني، تحديد المدة، الأجرة، والضمان. |
| **13** | **شاشة إنشاء عقد بيع وتمليك (Sale & Deed Contract)** | وثيقة مبايعة وتمليك، تدوين المساحة باللبنة الصنعانية، وأرقام البصائر وسجلات التعميد. |
| **14** | **شاشة معاينة العقد والطباعة PDF (Contract Preview)** | معاينة ورقة العقد الرسمية A4، الترويسة القانونية، الختم الرقمي وكود QR للتوثيق، مع زر طباعة فوري. |
| **15** | **شاشة المحادثات والتواصل (Chat & Inquiries)** | محادثة مباشرة بين الباحث والمالك مع اقتباس كرت العقار المعني والتفاوض اللحظي. |
| **16** | **الملف الشخصي والإعدادات (Profile & Settings)** | بيانات الحساب، العقارات المنشورة، العقود الموثقة، وتبديل اللغات والمظهر. |
| **17** | **لوحة تحكم المدير (Admin Dashboard)** | مؤشرات أداء المنصة، إجمالي العقارات، نسبة التوثيق، وعدد الإعلانات المعلقة بانتظار الاعتماد. |
| **18** | **شاشة مراجعة طلبات النشر (Approvals Review)** | فحص العقارات المقدمة من الملاك، مراجعة الوثائق، وأزرار الاعتماد الفوري (Approve) أو الرفض (Reject). |

### 🧭 4. مسارات التنقل والتدفق (User Flows)

تم تمثيل العلاقات بين الشاشات بـ **19 مساراً ملوناً ومتحركاً (Animated SVG Flow Lines)**:

1. **مسار الدخول والتوثيق (أزرق سماوي)**:
   - `Splash (1)` ──> `Sign Up (2)` أو `Login (3)` ──> `Home (4)`.
2. **مسار الاستكشاف والبحث (تركوازي عقاري)**:
   - `Home (4)` ──> `Search Results (5)` أو `Map (10)` أو `Favorites (9)` ──> `Property Details (6)`.
3. **مسار التواصل والعقود الذكية (ذهبي عنبري)**:
   - `Property Details (6)` ──> `Owner Profile (11)` ──> `Chat (15)`.
   - `Property Details (6)` ──> `Rental Contract (12)` أو `Sale Contract (13)` ──> `Contract Preview & PDF (14)`.
4. **مسار نشر العقارات والمراجعة الإدارية (بنفسجي ووردي)**:
   - `Home (4)` ──> `Add Property (7)` ──> `Pick Location on Map (8)` ──> `Admin Review (18)`.
   - `Admin Dashboard (17)` ──> `Admin Review (18)` ──> **اعتماد النشر** ──> يظهر العقار فورياً في `Home (4)` و `Map (10)`.

| رقم الفحص | الإجراء المختبر | النتيجة | الحالة |

| **3** | مسارات التدفق وأسهم الربط | 19 مسار SVG ملون ومتحرك | ✅ نجح |
| **4** | التكبير والتصغير والتحريك (Pan & Zoom) | تكبير سلس، تصغير سلس، وإعادة ضبط | ✅ نجح |
| **5** | محاكي الهاتف الحي (Simulator) | يعمل بسلاسة وينتقل بين كافة الشاشات | ✅ نجح |
| **6** | البحث والتصفية والمفضلة والخريطة | استجابة فورية ونقاط تجميع جغرافية | ✅ نجح |
| **7** | إضافة عقار ومراجعته من الإدارة | إرسال الإعلان واعتماده وظهوره بالرئيسية | ✅ نجح |
| **8** | إنشاء عقد إيجار/بيع ومعاينة الطباعة | توليد صك العقد مع الختم الرقمي وكود QR وأمر الطباعة | ✅ نجح |
| **9** | تبديل اللغات (عربي RTL / إنجليزي LTR) | تبديل الاتجاه والنصوص تلقائياً | ✅ نجح |
| **10** | فحص Console في المتصفح | **0 أخطاء جافاسكريبت (Zero JS Errors)** | ✅ نجح |
| **11** | التوافق مع شاشة الهاتف والكمبيوتر | استجابة كاملة للشاشات الكبيرة والمحمولة | ✅ نجح |

### 🔍 6. جدول توضيح الوظائف (الحقيقية vs المحاكاة)

لضمان الشفافية المطلقة والالتزام بتعليمات المشروع:

| الوظيفة في النموذج | نوع التنفيذ | آلية العمل |
|:---|:---:|:---|
| **التنقل بين الشاشات والكانفاس** | **حقيقي 100%** | معمارية SPA تفاعلية عبر DOM وCSS Transforms وJavaScript. |
| **التكبير والتصغير وتوسيط الشاشات** | **حقيقي 100%** | مصفوفة تحويل ديناميكية Matrix Transform مع معالجة أحداث الفأرة. |
| **توليد صك العقد وتنسيق الطباعة A4** | **حقيقي 100%** | ربط فوري لبيانات الأطراف وتوليد وثيقة مجهزة للطباعة بصيغة PDF. |
| **التفاعل مع الخريطة ونقاط التجميع** | **حقيقي 100%** | محرك SVG Vector Map تفاعلي مع كروت منبثقة تفاعلية. |
| **إضافة العقار والاعتماد الإداري** | **محاكاة وظيفية** | تُحفظ العقارات محلياً في الذاكرة لتجربة دورة الاعتماد دون الكتابة في قاعدة بيانات Supabase. |
| **تسجيل الدخول وOTP الواتساب** | **محاكاة تفاعلية** | نموذج توضيحي لتجربة المستخدم دون إرسال رسائل SMS فعلية. |
| **المحادثات المباشرة (Chat)** | **محاكاة تفاعلية** | واجهة محادثة جاهزة تعرض أسلوب التفاوض واقتباس كروت العقار. |
