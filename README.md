# بوابة اليمن العقارية — Yemen Real Estate Portal
منصة عقارية وطنية متكاملة وموثوقة لبيع وشراء وتأجير العقارات في كافة المحافظات اليمنية.

---

## 🌟 نظرة عامة
تم تصميم وبناء **بوابة اليمن العقارية** لتقديم تجربة عقارية عملية وسريعة وآمنة للمواطنين والمستثمرين والمكاتب العقارية في اليمن. يدعم النظام التشغيل على الهواتف الذكية (Android و iOS) ومتصفحات الويب (Flutter Web) ولوحة تحكم إدارية موحدة.

---

## 🎯 القرارات المعتمدة المطبقة في النظام
1. **طريقة نشر العقارات ("self_review")**: ينشر المستخدم إعلانه ذاتياً بعد مراجعته الشخصية، مع توفير نظام إبلاغ فوري عن المخالفات لمراجعة الإدارة.
2. **صلاحيات الزائر والحساب ("guest_account")**: إمكانية التصفح الكامل والبحث والتصفية للزائر، مع طلب تسجيل الدخول عند الرغبة في إضافة عقار، إرسال طلب استئجار، أو حفظ العقار في المفضلة.
3. **العمولة ("both")**: إمكانية تحميل العمولة على البائع أو المشتري أو كلاهما بحسب الاتفاق الموثق.
4. **احتساب العمولة ("manual")**: تسجيل يدوي للعمولة بواسطة المسؤول وفق بيانات الصفقة، دون افتراض نسبة ثابتة أو اقتطاع إلكتروني.
5. **طلبات الاستئجار ("request")**: إرسال طلب استئجار مبدئي برقم مرجعي فريد للمتابعة دون أن يعد عقداً ملزماً.
6. **المحادثة ("external")**: التواصل المباشر عبر تطبيق WhatsApp والاتصال الهاتفي الخارجي بروابط مهيأة وآمنة.
7. **قاعدة البيانات ("free_cloud")**: استخدام PostgreSQL وSupabase مع خطة مجانية وسياسات أمان Row Level Security (RLS) صارمة.
8. **لوحة الإدارة ("both")**: لوحة تحكم متجاوبة للويب والأجهزة المحمولة مع صلاحيات موحدة للمديرين.
9. **نطاق المواقع ("one")**: دعم النطاق الجغرافي الأساسي (أمانة العاصمة صنعاء وأحيائها الرئيسية) مع بنية قابلة للتوسع إلى باقي المحافظات.

│   └── utils/               # أدوات التنسيق، التجاوب، والتحقق
├── models/                  # نماذج البيانات (Freezed / JSON)
├── providers/               # إدارة الحالة بواسطة Riverpod
├── repositories/            # طبقة المستودعات والتعامل مع البيانات
├── services/                # خدمات التخزين، الاتصال الخارجي، وSupabase
├── shared/widgets/          # مكونات الواجهة المشتركة والشعار الأصلي
└── features/                # الوحدات الوظيفية المستقلة
    ├── admin/               # لوحة الإدارة والإحصائيات والتقارير
    ├── auth/                # تسجيل الدخول، إنشاء الحساب، والاستعادة
    ├── favorites/           # قائمة العقارات المفضلة
    ├── home/                # الصفحة الرئيسية والبحث السريع
    ├── profile/             # الملف الشخصي وإدارة عقارات المستخدم
    ├── properties/          # تفاصيل العقار وإضافة وتعديل العقارات
    ├── property_requests/   # طلبات الاستئجار والمتابعة
    └── search/              # البحث المتقدم والتصفية متعددة المعايير

## 🗄️ إعداد قاعدة البيانات (Supabase PostgreSQL)
1. أنشئ مشروعاً جديداً على [Supabase](https://supabase.com).
2. انتقل إلى **SQL Editor** في لوحة تحكم Supabase.
3. نفّذ ملف الترحيل الأولي الموجود في:
   `supabase/migrations/20261016_initial_schema.sql`
4. نفّذ ملف البيانات الأولية:
   `supabase/seed.sql`
5. نفّذ إعداد حاوية تخزين الصور:
   `supabase/storage_setup.sql`

### تعيين أول مدير عام للمنصة:
بعد إنشاء أول حساب عبر التطبيق بالبريد الإلكتروني، قم بترقية الحساب إلى `super_admin` بتنفيذ الأمر التالي في Supabase SQL Editor:
```sql
UPDATE public.profiles
SET role = 'super_admin', is_verified = TRUE
WHERE id = (SELECT id FROM auth.users WHERE email = 'admin@yemenrealestate.local');
```

## 🚀 التشغيل المحلي
### 1. المتطلبات
- Flutter SDK (الإصدار 3.32.8 أو أحدث)
- متصفح Google Chrome أو محاكي Android

### 2. تثبيت الحزم
```bash
flutter pub get
```

### 3. تشغيل التطبيق في وضع التطوير (الويب)
```bash
flutter run -d chrome
```

### 4. تمرير بيانات Supabase الحقيقية (اختياري)
عند الرغبة في الربط مع مشروع Supabase حقيقي، مرر المفاتيح أثناء التشغيل:
```bash
flutter run -d chrome --dart-define=SUPABASE_URL=https://your-project.supabase.co --dart-define=SUPABASE_ANON_KEY=your-anon-key
```
*ملاحظة: إذا لم تُمرر المفاتيح، يعمل التطبيق تلقائياً في "الوضع التجريبي الآمن" ببيانات واقعية تحاكي السوق اليمني.*

## 🔒 الأمان والخصوصية
- تفعيل سياسات Row Level Security (RLS) على كافة جداول قاعدة البيانات.
- منع تعديل رتبة المستخدم (`role`) من خلال دوال وسياسات أمان محمية.
- استخدام مفتاح Supabase Anon فقط في واجهات العميل دون تضمين أي مفاتيح `service_role`.
- التحقق من أحجام وصيغ الصور المرفوعة (حد أقصى 5 ميجابايت بصيغ JPG, PNG, WEBP).
